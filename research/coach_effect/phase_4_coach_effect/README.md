# Phase 4 — Coach Effect framework

`analysis.py` measures PAE/PCAE overlap and residualizes each signal against the other. It emits
three conceptual research columns: unique QB development, unique play calling, and a shared
standardized signal. It does not combine them into a score.

The conceptual framework retains symbolic `w_Q`, `w_P`, and `w_S`. Future values must be
estimated from expanded historical coverage, reliability, and out-of-sample validation. They
must not be chosen because they produce attractive rankings.
